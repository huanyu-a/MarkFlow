# MarkFlow 技术架构设计

> 本文档定义 MarkFlow 项目的整体架构、模块划分与关键技术方案。
> 定位：一个**纯前端、零后端**的「Markdown / HTML 多场景渲染与导出工作台」。把同一份内容渲染成面向不同受众的成品形态（长图文、A4 正式文档、单图/多图卡片、风格化 HTML），并一键复制或导出。

## 1. 核心七层架构

系统围绕“输入、共享渲染、场景、配置、导出、安全、AI 服务”组织，各场景共享底层的代码高亮、表格、图片、公式渲染能力：

1. **输入与 AI 指令层 (`src/components/editor/`, `src/lib/aiGuide.ts`)**：
   - Markdown 编辑 / HTML 编辑 / 对应场景的 AI 提示词指令与使用指南。
2. **共享渲染内核层 (`src/engine/`)**：
   - 从 `r-markdown` 移植升级的纯 TS 引擎。处理 Markdown 解析、通用块渲染、多行标签、中英文混排空格（pangu）、代码高亮（默认换行不横铺）、表格与公式（KaTeX）。
   - **`blockParser/`**：Markdown 块拆分与分类的公共逻辑，A4 文档和卡片模式共享。
3. **场景适配层 (`src/modes/`)**：
   - **长图文**：公众号、知乎等长文排版，附带独立的标题/摘要提取。
   - **A4 文档**：A4 固定比例，带页眉页脚，基于 Paged.js 的精确自动分页（段落/表格/图片智能跨页截断，续表标注，页眉页脚注入）。
   - **社交图文卡片**：小红书 3:4 / 9:16 等比例画布，封面图+自动多页内容图拆分，统一的留白呼吸感（四周 Padding 对齐）。
   - **自由 HTML（自由画布）**：基于 iframe 沙箱的高定网页渲染，供外部 AI 生成的复杂布局使用。
4. **配置与状态层 (`src/lib/rootStore.ts` / `appStore.ts` / `contentStore.ts`)**：
   - 基于 Zustand v5 的双 Store 设计：`useAppStore`（应用设置，经 `idbStorage` 节流写入 IndexedDB 持久化）与 `useContentStore`（编辑内容，独立 IndexedDB 存储）。`store.ts` 仅为兼容旧引用的转发 shim。
   - 主题色经 CSS 变量 `--accent` 全局驱动（预设色板来自 `@engine/composables/useTheme` 的 `THEMES`）。文档模式有独立的 `DocumentSettings` 配置。
5. **导出与复制层 (`src/lib/export*.ts` 与 `src/lib/export/`)**：
   - 各场景导出入口为 `src/lib/` 根目录下的 `exportPdf.ts` / `exportImage.ts` / `exportDocx.ts` / `exportPpt.ts`（含全图版与可编辑版）/ `exportSource.ts`，公共能力（长图合成、ZIP 打包）位于 `src/lib/export/`。
   - 覆盖复制富文本/HTML、前端高 DPI 截图（PNG/长图/批量图）、浏览器原生矢量 PDF 打印等能力，统一支持取消、超时与进度回调。
6. **安全层 (`src/lib/htmlSanitizer.ts` / `fetchSafe.ts` / `secureVault.ts`)**：
   - **HTML 净化**：基于标签/属性/URL 黑名单的 XSS 净化，已接入渲染主链路（Markdown 渲染、卡片模式、A4 分页内容、HTML 模式提取、AI 排版预览等）。
   - **网络请求防护**：外链资源与图床请求经 `fetchSafe` 做 SSRF 防护。
   - **密钥保护**：图床密钥默认不落盘；持久化时经 `secureVault`（PBKDF2-SHA256 + AES-GCM-256）口令加密。
   - iframe 沙箱默认禁用脚本，仅在用户显式开启后允许。
7. **AI 服务层 (`src/lib/aiService.ts` / `aiGuide.ts` / `aiSkills.ts`, `src/components/ai/`)**：
   - OpenAI 兼容的流式调用（SSE），支持重入保护、取消与撤销/重做历史栈。
   - 异常响应（如网关返回 HTML 错误页）转为固定友好提示，避免把原始响应倾泻给用户。

## 2. 技术栈清单

- **核心框架**：React 18 + Vite + TypeScript
- **样式**：Tailwind CSS v4
- **编辑器**：CodeMirror 6 (`@uiw/react-codemirror`)
- **状态管理**：Zustand v5（双 Store + IndexedDB 持久化）
- **数学公式**：KaTeX / MathJax（本地打包 + 动态 import 懒加载）
- **流程图**：Mermaid（本地打包，offscreen 预渲染管线）
- **图片导出**：modern-screenshot（iframeToBlob）
- **A4 分页**：Paged.js（`pagedjs@0.4.3`，集成在 `src/modes/document/paged/`）
- **ZIP 批量导出**：fflate（Web Worker 异步压缩）
- **Word / PPT 导出**：docx / pptxgenjs
- **PWA**：`vite-plugin-pwa`（Service Worker 缓存 + 桌面安装）
- **质量保障**：Vitest（403 用例）+ ESLint 9
- **部署方式**：纯静态输出，当前部署于自建服务器（nginx + EdgeOne CDN，`https://www.bx9y.com.cn/markflow/`），亦可部署于 GitHub Pages / Vercel

## 3. 开源归属与参考

- **[r-markdown](https://github.com/RobocopMao/r-markdown)**：公众号渲染引擎内核、自定义语法组件、主题系统、富文本/图片复制。（参考项目可单独克隆至 `vendor/r-markdown/` 进行追踪）
- **[html-anything](https://github.com/nexu-io/html-anything)**：HTML iframe 沙箱容器、`iframeToBlob` 高清导图方案、导出菜单抽象。（参考项目可单独克隆至 `vendor/html-anything/` 进行追踪）

**参考项目使用说明**：
- 参考项目不通过 git submodule 管理，用户可单独克隆到 `vendor/` 目录进行独立追踪
- 克隆参考项目：`git clone https://github.com/RobocopMao/r-markdown vendor/r-markdown` 或 `git clone https://github.com/nexu-io/html-anything vendor/html-anything`
- vendor/ 目录已加入 .gitignore，不会提交到主项目仓库
- **[awesome-design-md](https://github.com/VoltAgent/awesome-design-md)**：自由画布中的 Design Prompt 风格指令来源。
- **[guizang-ppt-skill](https://github.com/op7418/guizang-ppt-skill)**（AGPL-3.0）：自由画布中「电子杂志」「瑞士国际主义」的风格参考，以及网页 PPT 主题节奏、版式校验等经验启发。仅做设计经验与提示词层面的转译吸收，未并入其模板源码。
